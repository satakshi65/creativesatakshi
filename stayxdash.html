Stay X – One platform for rented accommodations

About Project

As the UI Designer and Frontend Developer for Stay X, I was responsible for shaping a seamless digital experience for users seeking rented accommodations. My goal was to create an intuitive, visually appealing platform that simplifies the search, booking, and management of rental properties. I collaborated closely with stakeholders to understand user pain points and translated those insights into wireframes and high-fidelity prototypes using Figma.

Leveraging HTML, CSS, Bootstrap, and React, I developed responsive interfaces that ensure accessibility across devices. I focused on optimizing user flows, integrating real-time property listings, and implementing secure booking features. Throughout the project, I prioritized performance, accessibility, and scalability, ensuring the platform could grow with user demand. This project allowed me to blend creativity with technical expertise, resulting in a robust solution that streamlines the rental process for both property owners and tenants.

  • Client : All India Hostels & PGs
  • Role : UI Designer & Frontend Developer
